# JavaScript Calculator

## Description

A browser-based calculator that performs basic arithmetic operations using JavaScript.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal numbers
- Clear button
- Backspace button
- Division-by-zero error handling
- Operator chaining
- Responsive design

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open index.html in a web browser.

## Project Purpose

This project was developed as part of the Oasis Infobyte Web Development & Designing internship to practice JavaScript logic, event listeners, CSS Grid, and user interaction.
