# To-Do List Web Application

## Description

A simple and responsive To-Do List web application built to help users manage their daily tasks.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- User-friendly interface
- Responsive design

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open index.html in a web browser.

## Project Purpose

This project was developed as part of the Oasis Infobyte Web Development & Designing internship to practice HTML, CSS, and JavaScript.
