# Nelson Mandela Tribute Page

## Description

A responsive tribute page dedicated to Nelson Mandela, highlighting his life, achievements, and contribution to the fight against apartheid and the promotion of equality and reconciliation.

## Technologies Used

- HTML5
- CSS3

## Features

- Hero section with title and tagline
- Nelson Mandela image
- Biography section
- Timeline of key achievements
- Inspirational quote section
- Responsive layout
- Multiple background colours
- Different font styles

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open index.html in a web browser.

## Project Purpose

This project was developed as part of the Oasis Infobyte Web Development & Designing internship to practice webpage structure, styling, responsive design, and presentation using HTML and CSS.
